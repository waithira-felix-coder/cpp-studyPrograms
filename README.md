# C++ Exercise Repository

This repository contains a collection of beginner and intermediate C++ programs created during. The exercises cover core programming skills, including variables, control flow, functions, arrays, pointers, classes, inheritance, and exception handling.

## Overview

- The files are small practice exercises meant to strengthen understanding of C++ syntax and programming concepts.
- Most programs are simple console applications that demonstrate one concept at a time.
- The `.exe` files are compiled output generated from the source programs and are intentionally excluded from version control.

## Topics covered

- Variables, constants, and input/output
- Conditional statements and loops
- Arrays, strings, and pointers
- Functions and pass-by-value/reference
- Structures and classes
- Constructors, destructors, and inheritance
- Exception handling and basic project-style exercises

## How to compile and run a program

Open a terminal in this folder and run a command like this:

```bash
g++ "filename.cpp" -o "filename.exe"
./filename.exe
```

## Notes

- This is a learning repository intended for practice and revision.
- Files are numbered and named by topic, so they can be reviewed in order or by concept.
- A few files may be experimental or contain short challenge exercises from class work.

## Suggested study order

1. Start with the basic `p1.cpp` to `p11.cpp` exercises.
2. Move to control-flow and data-structure files such as `struct.cpp`, `2DArray.cpp`, and `pointers1.cpp`.
3. Continue with object-oriented examples including `class.cpp`, `class Circle.cpp`, `SingleInheritance.cpp`, and `destructors.cpp`.
4. Finish with revision and project-style files such as `std mngt.cpp` and `std mngt use of switch.cpp`.
